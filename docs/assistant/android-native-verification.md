## Phone checks

Record each result as **pass**, **fail**, or **not tested**, with Android/One UI version, APK build ID, network state and a short observation. Do not share raw microphone recordings, credentials, account IDs or private app logs.

1. Install the verification APK from its build page. It uses the existing app package; install over the existing app when Android permits it. If Android reports a signing mismatch, stop and report the message instead of uninstalling: uninstalling can erase local credentials, preferences and drafts. The dedicated update channel separates OTA selection; this is not a separately installed app identity.
2. Confirm app launch, ordinary navigation and Assistant preview open/close. Type `set volume to 55%`, review it, then try `set volume to 90%`. Expect a preview for 55 and a clear 0–70 limit for 90, with no actual volume change. Try brightness/app opening too; the current build must never change settings or launch a catalog app from a preview.
3. In a normal signed-in session, select **Check Android support**. Confirm media/window hints and the reviewed Spotify/Clock launcher status match the device. Missing catalog handlers and a fixed-volume policy are valid bounded results, not proof of a broken executor. Repeated checks must not change settings, launch another app or request permissions.
4. Start a support check and close the modal, switch accounts, lock the phone or background the app. Returning must not restore the old report/draft or display a late result. Closing/reopening must start empty. Check the keyboard, screen reader, theme and layout as well.
5. Voice is a separate opt-in test. If the local recognizer is available, first deny microphone permission and confirm typing still works. Then allow session consent/OS microphone access and dictate synthetic English commands such as `set volume to 50 percent`. The transcript must remain editable and must not automatically review or execute. Missing local models/services should preserve typing and must not cause a cloud fallback or automatic model download.
6. With a working on-device engine, repeat capture with networking disabled. Test **Stop**, **Clear / cancel**, modal close, lock/background, permission revocation, a call/headphone interruption and app/process restart. Recording must stop; no automatic resume or restored transcript is allowed. Confirm the microphone indicator clears. Check local read-aloud, cancellation and that TTS never becomes a new command. Capture/playback are bounded to 30 seconds; Stop has a five-second deadline. Network observation/engine privacy needs independent evidence; offline success alone is insufficient to prove all engine behavior.
7. Record expected support/unavailability honestly. The first S25 run is one-device evidence, not an OEM/OS compatibility certification. Broaden to an older supported Android/OEM after the first device is clean.
